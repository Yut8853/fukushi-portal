# 人によるアクセシビリティ確認票

実施者、実施日、OS、ブラウザー、支援技術とバージョンを記録し、問題があればURL、操作手順、期待結果、実際の結果を残します。未実施の項目を「確認済み」に変更しません。

## 対象画面

- トップと相談先検索の3ステップ
- 検索結果
- DVカテゴリと緊急退出
- こころカテゴリ
- 自治体×カテゴリ
- 制度ガイド
- アクセシビリティ方針
- 公開データ

## キーボード

- TabとShift+Tabだけで全操作へ移動できる
- フォーカス位置と順序が分かる
- Enter、Space、矢印キー、Escが役割どおり動く
- フォーカスが緊急バナーや固定要素に隠れない
- 検索ステップ移動後、次に読むべき場所へフォーカスが移る

## スクリーンリーダー

- Windows: NVDA + ChromeまたはFirefox
- macOS/iOS: VoiceOver + Safari
- Android: TalkBack + Chrome
- 見出し一覧だけでページ構造を理解できる
- リンク名だけで移動先が分かる
- 電話番号が一桁ずつ理解できる
- 状態変更と検索結果が通知される
- 緊急情報が過度に繰り返されない

## 拡大・表示変更

- 200％および400％相当で横方向の読書を強制されない
- 320 CSS px相当で主要操作が欠けない
- 行間1.5、段落間隔2、文字間隔0.12em、単語間隔0.16emでも欠けない
- 文字だけを拡大してもボタンや電話番号が切れない
- ダークモードや高コントラスト設定でも意味が失われない

## 完了条件

- 重大な操作不能、情報欠落、誤読を解消する
- 軽微な問題は `/accessibility` の既知の課題へ掲載する
- 確認日と環境を `/accessibility` へ反映する
